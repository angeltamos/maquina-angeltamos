Política de privacidad

Aplicación: Máquina de Ángel Tamos · Responsable: titular del proyecto artístico Ángel Tamos · Contacto: angeltamos@gmail.com · Última actualización: 1 de noviembre de 2026

1. Alcance y finalidad

Máquina de Ángel Tamos es una herramienta privada para preparar y publicar contenido audiovisual y musical autorizado en las cuentas oficiales del titular. No proporciona registro de usuarios públicos ni ofrece una base de datos abierta de terceros.

2. Uso de los Servicios de la API de YouTube

Esta aplicación utiliza los Servicios de la API de YouTube cuando el propietario del canal autoriza el acceso mediante Google OAuth. La herramienta puede acceder, según los permisos efectivamente concedidos, al identificador y nombre del canal autorizado, a credenciales y tokens de autorización y a datos técnicos necesarios para subir videos aprobados, así como al estado e identificadores de esas publicaciones.

Se utiliza esa información únicamente para identificar el canal, autenticar la conexión, subir el contenido aprobado, gestionar las solicitudes de publicación y comprobar sus resultados. No se utiliza para crear perfiles publicitarios ni comercializar datos de la cuenta Google.

3. Datos tratados y procedencia

  • Datos de autorización: identificadores y tokens OAuth, y configuración técnica necesaria para operar las conexiones autorizadas.
  • Contenido: archivos de video o audio, títulos, descripciones, textos y metadatos aportados o aprobados por el titular.
  • Datos operativos: identificadores de publicaciones, resultados de envío, errores y registros técnicos necesarios para diagnosticar el proceso.

Estos datos proceden del titular, de los archivos aprobados y, cuando se autoriza, de las plataformas conectadas por sus API oficiales.

4. Almacenamiento y seguridad

La configuración y los tokens del publicador se gestionan en el entorno privado local de MDA, con acceso restringido al operador autorizado. Las páginas públicas de este repositorio GitHub Pages no contienen claves, secretos, tokens ni contenido audiovisual privado. Los registros y archivos operativos se conservan solo mientras sean necesarios para administrar las operaciones, atender incidencias y cumplir las obligaciones aplicables.

5. Destinatarios y terceros

Para efectuar publicaciones autorizadas, la herramienta comunica el contenido y los datos técnicos indispensables a la plataforma de destino (por ejemplo, YouTube). Otras integraciones —como Instagram, Facebook, TikTok o servicios técnicos de alojamiento temporal de video— solo se utilizan cuando están configuradas y autorizadas para la operación correspondiente. Cada servicio aplica también sus propias políticas.

No se venden datos personales ni se facilitan a anunciantes para segmentación comercial.

6. Revocación, eliminación y consultas

El propietario puede revocar el acceso de la aplicación a Google en las conexiones de su cuenta Google. La revocación impide nuevos accesos autorizados, sin sustituir la eliminación de datos o credenciales previamente conservados en el equipo local.

Para solicitar la revisión, corrección o eliminación de información almacenada por esta herramienta, escribir a angeltamos@gmail.com. El operador realizará la revisión y eliminación que corresponda en los registros y almacenamiento local, respetando obligaciones legales o de seguridad aplicables.

7. Sitio web público

Estas páginas son estáticas y no incorporan formularios de registro, publicidad ni tecnologías propias de seguimiento. GitHub, como proveedor de alojamiento, puede tratar datos técnicos de acceso conforme a sus propias políticas.

8. Políticas y actualizaciones

El uso de datos de Google y YouTube se encuentra sujeto asimismo a la Política de privacidad de Google y a las Condiciones del Servicio de YouTube. Esta política puede actualizarse si cambian las integraciones o el tratamiento de datos. La versión vigente estará disponible en esta página.
